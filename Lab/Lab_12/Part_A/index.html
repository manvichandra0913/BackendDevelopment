Lab 12 Part A

Programs to familiarize Server-Side Scripting using Node JS

This lab demonstrates server-side scripting using Node.js, Express.js APIs, EJS templates, and form handling.

Run Commands

npm install
npm run dev

Lab Tasks

  1. Basic server routes for name, roll number, and branch in text, HTML, and JSON formats.
  2. Calculator API for add, subtract, multiply, divide, modulus, and power operations.
  3. Student management routes for listing, viewing, and adding students.
  4. EJS timetable page with day, time, subject, and faculty.
  5. EJS student registration form and result page.

Important Routes

  • /name/text
  • /name/html
  • /name/json
  • /calculate?num1=10&num2=5&operation=add
  • /students
  • /students/1
  • /timetable
  • /register

Server URL

After running the server, open http://localhost:3000.
