# L04: HTTP Requests and Responses

This folder contains tasks 4 through 8 for HTTP responses, templating, Flask routes, and browser developer tools.

## Tasks

- `Task-4-HTML-Responses` - Node.js server returning HTML
- `Task-5-EJS-Templating` - Express app using EJS templates
- `Task-6-Flask-Hello-World` - basic Flask app
- `Task-7-Flask-Routes-JSON-POST` - Flask API with routes, JSON, and POST request handling
- `Task-8-DevTools` - browser DevTools screenshot

## How to Run

For Node.js tasks:

```bash
node server.js
```

For Flask tasks:

```bash
python app.py
```
