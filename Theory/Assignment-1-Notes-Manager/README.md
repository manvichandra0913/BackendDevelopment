# Assignment 1: Notes Manager

A simple browser-based Notes Manager built with HTML, CSS, and JavaScript.

## Features

- Add new notes
- Mark notes as completed or pending
- Edit existing notes
- Delete one note or clear all notes
- Filter notes by all, pending, or completed
- Save notes permanently in `localStorage`

## Files

- `index.html` - complete Notes Manager app

## How to Run

Open `index.html` in any modern web browser.
