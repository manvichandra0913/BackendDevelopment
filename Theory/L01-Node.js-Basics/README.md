# L01: Node.js Basics

This folder contains the first three Node.js practice tasks.

## Tasks

- `Task-1-Hello-World` - basic Node.js HTTP server
- `Task-2-Multiple-Routes` - server with multiple routes
- `Task-3-JSON-Data` - server returning JSON data

## How to Run

Open any task folder and run:

```bash
node server.js
```

Then visit `http://localhost:3000` in the browser.
